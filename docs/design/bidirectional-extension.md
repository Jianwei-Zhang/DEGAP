# 双向历史家族延伸

状态：设计已确认，实施中。本文描述目标行为，不代表所有入口已启用。

确认日期：2026-11-21。实施分支：`feat/bidirectional-gap-extension`。

## 目标

不再要求某一侧独自走完整个 gap。左右向内延伸，每次新结果与对侧全部历史版本检查闭合，避免较晚的错误延伸覆盖较早仍可连接的版本。本次同时更新底层、GapFiller、AutoGapfiller、CtgLinker 和 TelSeeker 的调用契约；不发布版本、不更新 CGAT 捆绑运行时。

这不是多分支局部组装搜索：每侧仍是一条延伸链，家族是这条链的历史快照。改善错误率和填补率是设计目的，需后续真实数据验证，不作为已测结论。

## 序列和调度

- `L0/R0` 为初始左右序列。`Li/Rj` 为对应侧的累计序列，不只是新增片段。
- 先检查第零代。若已闭合，直接结束，不运行延伸。
- 单 gap 顺序为 L1、R1、L2、R2……；每完成一次延伸，先检查闭合再执行下一侧。
- 新版本与对侧所有已有版本检查，包括第零代。例如 L3 可连接 R2，即使不能连接 R3，也采用 L3/R2。
- 没有可延伸 reads/contig、零增长或原有防循环规则触发，只停止该家族。保留其历史供另一侧继续匹配。
- 工具故障、损坏输出、程序异常与正常不可延伸分开，不能吞掉异常伪装成正常停止。
- 任一时刻获得合格闭合结果、全部家族停止，或共享预算耗尽，结束当前搜索。
- 未闭合时保留各侧有效累计结果和明确的未闭合状态，不把两侧直接拼接冒充填补成功。

## 预算

- 一个普通 gap 的总尝试轮数 = 左侧尝试轮数 + 右侧尝试轮数。
- 总延伸长度 = 左侧有效累计新增长度 + 右侧有效累计新增长度。
- 不包含初始序列，不重复累加历史累计版本，不扣除最后闭合重叠。
- 实际执行过的不可延伸尝试计入轮数，但不生成版本、不增加长度。
- 闭合检查不消耗延伸轮数。采用较旧版本闭合不退还已消耗预算。
- 轮数为硬限制；长度在启动下一轮前检查。最后一轮可越过长度上限，完整保留并检查闭合后停止，不截断组装结果。
- `None` 表示无限制；零预算仍允许第零代闭合检查，但不允许启动延伸。负限制应在入口明确拒绝。

## 闭合和唯一结果

先按方向、端点和重叠要求判定合格，再依次比较：

1. identity 越高越优；
2. identity 相同，有效重叠越长越优；
3. 再相同，端点未对齐部分越少越优；
4. 仍相同，固定家族/版本顺序打破平局。

保留现有闭合门槛的科学含义，不借此次改动静默放宽门槛。方向和裁剪坐标必须映射回完整累计序列。遍历完整个本次对侧家族集合后，只输出一个最佳闭合结果并停止；不是遇到第一个命中就停止，也不继续延伸来比较尚未产生的版本。

结果记录双方家族、版本、序列内容标识、完整序列坐标、identity、重叠及拼接边界。日志可保留候选比较证据，但不产生多个最终分支。重复区的最高 identity 不等同于真实正确性；需保留证据供验证。

## 共享和隔离

共享 reads、预处理产物、随机访问索引和统计；不启动两套独立全流程。

各家族独立持有方向、当前序列、seed、已用 reads、上一轮 reads、停止原因和延伸历史。禁止跨家族合并 `usedReads` 后据此判断无新 reads。

仅在输入内容、方向、参数和工具契约一致时复用筛选/比对/组装结果。不能直接将一侧的候选 reads 或局部组装用于另一侧。同一不可变版本对的闭合结果只计算一次。家族历史及恢复必需文件不受普通轮次清理删除。

## 模式适配

### GapFiller / AutoGapfiller

GapFiller 管理两个家族。AutoGapfiller 每个 gap 创建一个双向任务，取消同一 gap 的 left/right 独立重复运行；同步更新任务汇总、结果导入和可视化，不能只改命令生成。

### CtgLinker

当前端点 A 和候选库中的 B/C/D 等端点均可建立家族。一次当前端点连接搜索共用轮数和长度预算，累计所有参与家族；不是每个候选一份，也不是整个 CtgLinker 项目共用一份。

按稳定候选顺序交替推进当前端点与候选端点：A、B、A、C、A、D……；候选轮转，一侧停止后跳过但保留历史。只检查当前端点家族与候选家族的连接，不凭此额外创建候选之间的连接。单个候选时退化为普通左右交替。当前端点停止后，候选继续轮转。较多候选会分摊有限预算。

必须保存候选原始 contig/端点身份、方向和完整序列来源。当前端点库保存完整 contig/scaffold 及反向互补候选；比对时截取的端点片段不得当作完整 contig。闭合结果应正确重建完整序列、AGP 和已用 contig 信息。候选序列或连接上下文改变后，不复用陈旧结果。

### TelSeeker

复用单轮延伸和家族状态机制，但没有真实对侧时仍为单端任务，保留端粒检测及停止条件。不得将当前兼容字段 `terminalSeq=initialSeq` 当作真实对侧进行自闭合。

## CLI 和恢复

- 新命令不再传 `--flag`。旧命令仍可解析，明确提示已忽略，不报错；内部方向信息保留。
- 新断点有明确版本，原子写入，保存家族、预算、轮转位置、停止原因、检查结果、输入/参数身份。
- 恢复时验证历史内容及所需产物；不重复计算已有效完成的步骤、不重复扣预算。中断中的尝试与已完成尝试需可区分。
- 本次不自动导入旧单侧历史。遇到旧 `round:N` 等任务，要求使用新目录，不覆盖、不假装已迁移。安全识别的 reads 预处理/索引可复用。
- 结果/断点损坏或输入改变时明确报告，不能当空结果或重新开始覆盖已有任务。
